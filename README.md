# MaaPocket

**在 Android 手机本机上跑 MaaFramework 自动化** —— 崩坏：星穹铁道 / 绝区零 / 明日方舟：终末地的迁移版。

不需要电脑，不需要 ADB，不需要数据线。装 APK + 授权 Shizuku（或 root），手机上直接跑。
